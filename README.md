# 倒立振子制御シミュレータ Webアプリ

身近な例（傘立て制御）から学ぶ制御工学の体験型Webシミュレータです。
高校生・大学学部生向けのオープンキャンパスや体験講義で、各自のスマートフォンまたはPCから直接アクセスして操作できます。

## 特徴

- **インストール・ビルド不要**: 完全クライアントサイド（HTML5 / JavaScript / Canvas / KaTeX / Tailwind CSS）で動作
- **GitHub Pages対応**: リポジトリ直下に配置されており、GitHub Pagesですぐに静的配信可能
- **ハイブリッド・レスポンシブ設計**:
  - **スマートフォン（縦画面）**: Canvasシミュレータを画面上部に固定し、下部の解説・パラメータをスクロール操作
  - **PC・タブレット（横画面）**: 左ペインに解説・パラメータ操作、右ペインにシミュレータ画面を固定
- **厳密な物理計算**: 倒立振子の非線形運動方程式をルンゲ＝クッタ4次法（RK4）でリアルタイム数値積分
- **シンプルなUI**: アカデミック・エンジニアリングに適した、絵文字や過剰な配色を排除したモノトーン主体のデザイン

## ステップ構成

1. **Step 0: 自然落下（制御なし）**: 重力によって傘が必ず倒れてしまうことを観察
2. **Step 1: ON/OFF制御**: 傾いた向きに一定の力で押すと、ガクガク激しく振動（チャタリング）して倒れることを体験
3. **Step 2: 比例制御 (P)**: 傾きの大きさに応じた力で押すと、倒れにくくはなるがユラユラ揺れ続けることを体験
4. **Step 3: PD制御**: 倒れる速度にブレーキをかける微分項を加え、直立安定化を達成（ただし台車が流れる）
5. **Step 4: 完全制御（PID/状態フィードバック）**: 台車位置も中央に戻す制御を加え、直立・中央静止および外乱からの自律復帰を達成

## ファイル構成

```
open-campus-/
├── index.html            # メインHTML
├── css/
│   └── style.css         # スタイル定義（タッチ誤爆防止、レスポンシブ）
├── js/
│   ├── physics.js        # 倒立振子の物理モデル計算（非線形運動方程式・RK4）
│   ├── controller.js     # Step 0〜4 の制御アルゴリズム
│   ├── renderer.js       # HTML5 Canvas 描画エンジン（Retina対応）
│   ├── stepManager.js    # ステップ進行、パラメータ連動、KaTeX数式
│   └── main.js           # イベントリスナー、アニメーションループ
├── README.md             # 本ドキュメント
└── 設計書.md             # 詳細設計書
```

## ローカル起動方法

静的ファイルのみで構成されているため、ローカルサーバーで起動するか、ブラウザで `index.html` を開くだけで動作します。

```bash
# Pythonを使用する場合
python -m http.server 8000

# Node.js (npx) を使用する場合
npx serve .
```
ブラウザで `http://localhost:8000` にアクセスしてください。
