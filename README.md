# 倒立振子制御シミュレータ Web教材

身近な「手のひらの上で傘を立てる」体験から制御工学の基礎を直感的に学ぶ、オープンキャンパス向けの体験型Web教材です。
高校生や学部生が、各自のスマートフォン・タブレット（iPad等）・PCから直接アクセスして操作できます。

---

## 🎯 特徴

- **インストール・ビルド不要**: 完全クライアントサイド（HTML5 / Vanilla JavaScript / Canvas / Tailwind CSS）で動作。
- **超軽量・ゼロ依存**: 外部数式ライブラリ等の依存を排除し、高速な初期ロードとスムーズな描画（60fps）を実現。
- **マルチデバイス・ハイブリッド設計**:
  - **スマートフォン & タブレット（縦画面）**: 上部に広々としたシミュレータ、下部に押しやすい大型ボタンとスライダーを配置。
  - **PC & タブレット（横画面）**: 左側に操作パネル、右側にシミュレータが広がる左右2ペイン構成へ自動適応。
- **直感的な操作性**:
  - **風の入力（外乱 1.0N）**: 押しやすい大型ボタンで左右から風を吹かせ、制御系の自律復帰をリアルタイムに体験。
  - **パラメータ設定**: 左上メニュー（≡）から、初期傾き角（θ₀）、傘の全体の長さ（L）、傘の重さ、手の質量を自由に変更可能。
  - **洗練されたミニマルUI**: Lucide Icons 仕様のインラインベクターSVGを採用したクリーンなデザイン。
- **厳密な物理シミュレーション**: 倒立振子の非線形運動方程式をルンゲ＝クッタ4次法（RK4）でリアルタイム数値積分。

---

## 📚 ステップ構成

1. **Step 0: 自然落下（制御なし）**  
   力を一切加えない場合、重力によって傘が必ずパタンと倒れてしまう様子を観察します。
2. **Step 1: ON/OFF制御**  
   傾いた向きへ一定の力で押し戻します。ガタガタ激しく振動（チャタリング）して倒れてしまうことを体験します。
3. **Step 2: 比例制御 (P)**  
   傾きの大きさに応じた力（ばねのような力）で手を動かします。倒れにくくはなりますが、左右に揺れ続けてしまうことを体験します。
4. **Step 3: PD制御**  
   倒れる「速さ」を感じてブレーキをかける微分項（Kd）を追加します。左右の揺れが収まり、傘が垂直にピタッと安定します。
5. **Step 4: 同時制御（状態フィードバック）**  
   傘を立てながら、手をもとの位置（中央）に戻す制御（Lp, Ld）を加えます。風ボタンで外乱を与えても倒れずに中央へ復帰する「神業制御」を体験します。

```
open_campus/
├── index.html            # メインHTML（レスポンシブUI骨格、SVGアイコン）
├── css/
│   └── style.css         # スタイルシート（iPad/スマホ/PC対応、ミニマルデザイン）

│   ├── physics.js        # 物理モデル計算（非線形運動方程式・RK4数値積分）

│   └── main.js           # アプリ初期化・アニメーションループ・イベント配線
├── QRコード.png           # オープンキャンパス会場用アクセスQRコード画像
├── 設計書.md             # システム詳細設計書
└── README.md             # 本ドキュメント
```

## 🚀 起動方法

静的ファイルのみで構成されているため、ブラウザで直接 `index.html` を開くか、ローカルサーバーで起動できます。

```bash
# Python を使用する場合
python -m http.server 8000

# Node.js を使用する場合
npx serve .
```

ブラウザで `http://localhost:8000`（または表示されたURL）にアクセスしてください。

GitHub Pages を有効にすれば、URLをQRコード化してオープンキャンパス来場者のスマートフォンですぐに体験できます。
